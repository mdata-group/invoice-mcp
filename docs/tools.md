# 工具詳表

兩個工具都是**唯讀**的。

## `get_current_invoice_period`

無參數。回傳今天所屬的發票期別。

| 欄位 | 說明 |
| --- | --- |
| `period` | 5 碼期別字串，例如 `11506` |
| `roc_year` | 民國年，例如 `115` |
| `western_date` | 西元日期 |
| `current_month` | 當前月份 1–12 |

**為什麼需要這個工具**：民國年換算（西元年 − 1911）與雙月期別規則容易被 LLM 算錯，且錯了還會語氣自信。查任何期別前先呼叫這個。

## `list_invoices(period, page?)`

| 參數 | 必填 | 說明 |
| --- | --- | --- |
| `period` | ✅ | 5 碼 ROC 期別 |
| `page` | ❌ | 頁碼，預設 1 |

回傳每張發票的：發票號碼、開立時間、金額、幣別、賣方（統編／店名／分類）、品項清單（名稱／數量／單價／小計）、中獎狀態與中獎金額，外加 `paging`（`current_page` / `total_pages` / `total_count`）。

**中獎資訊是內含的** —— 不需要另一個工具，直接從清單過濾即可。

### 期別規則（最常踩的坑）

5 碼 = 3 碼民國年 + 2 碼月份，月份**只能是每組雙月的偶數月**：

| 期別月份 | 涵蓋 |
| --- | --- |
| `…02` | 1–2 月 |
| `…04` | 3–4 月 |
| `…06` | 5–6 月 |
| `…08` | 7–8 月 |
| `…10` | 9–10 月 |
| `…12` | 11–12 月 |

**奇數月一律無效** —— `11505` 會被拒絕，要用 `11506`。

一整年 = 6 個期別。民國 115 年為 `11502, 11504, 11506, 11508, 11510, 11512`。

### 分頁

`paging.total_pages` 大於 1 時要遞增 `page` 逐頁取。問「今年總共花多少」這類問題時，務必確認每個期別都翻完，否則金額會少算。
