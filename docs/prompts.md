# 範例 Prompt

接上後直接複製使用。

## 中獎查詢

```text
幫我看這期發票有沒有中獎，中了哪幾張、各中多少。
```

```text
把我今年到目前為止所有中過獎的發票列出來，含店家跟金額。
```

## 消費分析

```text
我這期在便利商店總共花了多少錢？列出前五筆最貴的。
```

```text
統計我今年在咖啡上的花費。記得一整年有 6 個期別都要查。
```

```text
比較我這期跟上一期的總消費，說明主要差異在哪些類別。
```

## 品項層級

```text
我上個月買最多次的商品是什麼？列出前十名跟次數。
```

```text
找出我這期單價超過 1000 元的品項。
```

## 小技巧

- 先讓它呼叫 `get_current_invoice_period` 確認期別，可避免民國年算錯。
- 問「今年」時明確提醒「一整年有 6 個期別」，避免只查一期就作答。
- 資料量大時提醒它「把每一頁都翻完再統計」。
